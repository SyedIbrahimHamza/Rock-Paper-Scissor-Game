# Rock Paper Scissors Game

A simple command-line Rock, Paper, Scissors game built with Python. Play against the computer, track your score, and enjoy multiple rounds until you choose to quit.

## Features

* Play against the computer
* Random computer choices
* Score tracking
* Input validation
* Multiple rounds

## Technologies

* Python
* Random module

## Run the Project

```bash
python main.py
```
